## The name

<span class="copt">Ⲁⲧⲣⲓⲡⲉ</span>, Atripe, is the Upper Egyptian town that
gave Shenoute his epithet. The White Monastery stood just outside it. The
site is named after a place mainly because the alternative was naming it
after a person, and that seemed presumptuous.

## What it is

Notes, kept in public so they are harder to lose. Written by one person who
reads Coptic slowly. Where a note is confidently wrong, it is wrong in a way
that can be corrected — please do.

## How it is built

Static pages from [Zola](https://www.getzola.org), built and deployed by
GitHub Actions, hosted on GitHub Pages. The development environment is a
Nix flake, so `nix develop` then `zola serve` is the whole setup.

No JavaScript, no analytics, no cookies, no fonts loaded from anyone else's
server. The page you are reading is a few kilobytes of HTML and one
stylesheet.

arrived with.
