Coptic manuscripts are written *scriptio continua*: the letters run on
without spaces. Scribes sometimes marked a word-end with a hook above the
last letter, a circumflex over the final vowel of a monosyllable, or in later
manuscripts two dots or a gap. None of it is systematic and none of it is
frequent.{{ cite(t="Till, <em>BIFAO</em> 60 (1960), 151. Section numbers throughout are his.") }}

## Why editors divide

An edition has to put the spaces somewhere. Till holds that a Coptic text
printed undivided suggests its editor did not understand it. He allows one
exception: where a text is not understood, any division is a guess, so print
it undivided.

## The criterion

Division exists to make the text understood quickly and surely. Till admits
no other consideration — not grammar, not phonology, not the structure of the
editor's own language. All forty rules follow from this one test.

## Systems he rejects

**One notion, one word.** The editor writes as one word what he would
translate as one word. The result depends on the editor's language rather
than on Coptic.

**The bound group.** The older Egyptological practice joined everything
falling under one principal accent. It produces strings like
{{ copt(t="ⲉⲕϣⲁⲛⲡⲛ̄ⲕⲉⲧⲉⲕⲙ̄ⲧⲉⲕⲛϩⲉ") }}, which have to be taken apart before they
can be read. Till compares it to printing a French translation as
*siaussitutirestonépée*.

The practice had a reason. When it was framed, the reduced forms — the
construct and prepersonal states — had only recently been described, and
joining them to their accented host marked them off from the absolute forms.
Those forms are now well known, so the reason has
lapsed.{{ cite(t="pp. 152–153. Amélineau made the same criticism in <em>Sphinx</em> 17 and 18; Till in <em>Aegyptus</em> 14 and <em>ZÄS</em> 77.") }}

**Atomisation.** Separating every element gives
{{ copt(t="ⲉ ⲕ ϣⲁⲛ ⲡ ⲕⲉ ⲧⲉⲕⲙ ⲧⲉ ⲕ ⲛϩⲉ") }}. The reader has to put it back
together. Till's answer is that a useful system lies between the two
extremes and has to be worked out case by case.

## Ambiguities

Without a convention the same sequence of letters carries different
meanings.{{ cite(t="pp. 154–155.") }}

| Joined | Separated |
|---|---|
| {{ copt(t="ⲙⲉⲣⲉⲡϫⲟⲉⲓⲥ ⲥⲙⲟⲩ") }} the Lord does not bless | {{ copt(t="ⲙⲉⲣⲉ ⲡϫⲟⲉⲓⲥ ⲥⲙⲟⲩ") }} love the Lord! bless… |
| {{ copt(t="ⲡⲁⲧⲙⲟⲣⲧ") }} the beardless one | {{ copt(t="ⲡⲁ ⲧⲙⲟⲣⲧ") }} the bearded one |
| {{ copt(t="ⲙⲛⲧⲟⲩϩⲁⲏ") }} they have no end | {{ copt(t="ⲙⲛ ⲧⲟⲩϩⲁⲏ") }} with your end |
| {{ copt(t="ϯϩⲓⲥⲉ") }} I suffer | {{ copt(t="ϯ ϩⲓⲥⲉ") }} to give pain |
| {{ copt(t="ⲉϫⲛⲟⲩ") }} to ask | {{ copt(t="ⲉϫⲛ ⲟⲩ") }} on what? |
| {{ copt(t="ⲟⲩⲁⲡⲉ") }} a head | {{ copt(t="ⲟⲩⲁ ⲡⲉ") }} he is one |
| {{ copt(t="ⲛϭⲓⲛϣⲁϫⲉ") }} the discourses | {{ copt(t="ⲛϭⲓ ⲛϣⲁϫⲉ") }} that is, the words |
| {{ copt(t="ⲉⲛⲉⲛⲧⲕⲟⲩⲱϩⲥ") }} if you were a shepherd | {{ copt(t="ⲉⲛⲉ ⲛⲧⲕ ⲟⲩⲱϩⲥ") }} are you a shepherd? |

{{ copt(t="ⲡⲁⲧⲙⲟⲣⲧ") }} and {{ copt(t="ⲡⲁ ⲧⲙⲟⲣⲧ") }} are the same letters in
the same order and mean opposite things.

## Zachariah 14:9

The Achmimic translator of the Minor Prophets worked from a Sahidic text
written without divisions. He read {{ copt(t="ⲉⲟⲩⲁⲡⲉ") }} as
{{ copt(t="ⲉ-ⲟⲩ-ⲁⲡⲉ") }}, "a head", where it was {{ copt(t="ⲉⲟⲩⲁ ⲡⲉ") }},
"being one", and translated that the Lord would become a head and his name a
head.{{ cite(t="§ 32, p. 163.") }} He read Coptic natively and had the
manuscript in front of him.

## The rules

Forty rules, in Till's grouping. The [cheat sheet](cheatsheet.pdf) has all of
them with examples on one page.

### Determiners

Every article joins the following word: definite, indefinite, demonstrative,
possessive. Joining keeps each one distinct from a word spelt the same way.
The demonstrative rule matters most outside Sahidic, since Achmimic,
Subachmimic, Fayyumic and Bohairic write the demonstrative article and the
demonstrative pronoun alike.{{ cite(t="§§ 1–5, pp. 155–157.") }}

| Joined | Separated |
|---|---|
| {{ copt(t="ⲟⲩⲱⲃ") }} a thing | {{ copt(t="ⲟⲩ ⲡⲉ ⲡⲁⲓ") }} what is this? |
| {{ copt(t="ϩⲉⲛϣⲁϫⲉ ⲁⲛ") }} not words | {{ copt(t="ϩⲛ ϣⲁϫⲉ ⲁⲛ") }} not in words |
| {{ copt(t="ⲡⲉⲓⲣⲱⲙⲉ") }} this man | {{ copt(t="ⲡⲉⲓ ⲟⲩⲣⲱⲙⲉ ⲡⲉ") }} this is a man |
| {{ copt(t="ⲛⲁⲉⲓⲟⲧⲉ") }} my parents | {{ copt(t="ⲛⲁ ⲛⲁⲉⲓⲟⲧⲉ") }} those of my parents |

### Conjugation and subject

A conjugation prefix with a pronominal subject joins its predicate, whether
the predicate is verbal or not; Till compares personal endings elsewhere,
where nobody writes *ama v it*. The prefix also joins a nominal subject,
which is what separates "the Lord does not bless" from "love the Lord!". The
suffix conjugation does not join a following nominal
subject.{{ cite(t="§§ 6–12, pp. 157–158.") }}

| Joined | Separated |
|---|---|
| {{ copt(t="ⲁϥⲛⲁⲩ") }} he saw | {{ copt(t="ⲡⲁⲥⲟⲛ ϩⲙ ⲡⲉϥⲏⲓ") }} my brother is in his house |
| {{ copt(t="ⲛⲉϥϩⲙ ⲡⲉϥⲏⲓ") }} he was in his house | {{ copt(t="ⲡⲉϫⲉ ⲡϫⲟⲉⲓⲥ") }} the Lord said |
| {{ copt(t="ⲙⲉⲣⲉⲡϫⲟⲉⲓⲥ ⲥⲙⲟⲩ") }} the Lord does not bless | {{ copt(t="ⲛⲁⲛⲟⲩ ⲡⲉⲕⲛⲁ") }} your mercy is good |

### The infinitive and its object

A reduced infinitive is separated from its nominal object, including where
the infinitive is a single letter and where the pair translates as one word.
Till calls a joined infinitive and object the largest source of obscure
letter-sequences in Coptic. The exception is {{ copt(t="ⲣ") }} before a Greek
verb, which stays joined because the combination has become one
verb.{{ cite(t="§§ 13–18, pp. 158–160.") }}

| Joined | Separated |
|---|---|
| {{ copt(t="ⲛⲟⲩϫⲱⲱⲙⲉ") }} of a book, to a book | {{ copt(t="ⲛ ⲟⲩϫⲱⲱⲙⲉ") }} to bring a book |
| {{ copt(t="ⲁϥϣⲱⲡ") }} he bought | {{ copt(t="ⲁϥϣ ⲱⲡ") }} he could count |
| {{ copt(t="ⲙⲉϩϣⲟⲙⲛⲧ ⲛϫⲡⲟϥ") }} third basket | {{ copt(t="ⲙⲉϩ ϣⲟⲙⲛⲧ ⲛϫⲡⲟϥ") }} fill three baskets |
| {{ copt(t="ⲣⲁⲓⲧⲉⲓ") }} to ask (αἰτεῖν) | {{ copt(t="ⲣ ⲛⲟⲃⲉ") }} to sin |

### Prepositions

Prepositions are separated. The one-letter prepositions {{ copt(t="ⲉ") }} and
{{ copt(t="ⲛ") }} are the exception and stay joined, by a convention taken
over from Hebrew and Arabic; {{ copt(t="ⲉ") }} cannot always be detached in
any case.{{ cite(t="§§ 19–22, pp. 160–161.") }}

| Joined | Separated |
|---|---|
| {{ copt(t="ⲙⲛⲧⲉϥ ⲙⲁⲁⲩ") }} he has no mother | {{ copt(t="ⲙⲛ ⲧⲉϥⲙⲁⲁⲩ") }} with his mother |
| {{ copt(t="ⲁⲓⲛⲁⲩ ⲉⲩⲣⲱⲙⲉ") }} I saw a man | {{ copt(t="ϫⲓⲛ ϩⲧⲟⲟⲩⲉ ϣⲁ ⲣⲟⲩϩⲉ") }} from morning to evening |

### Circumstantial, preterite, relative

Circumstantial {{ copt(t="ⲉ") }} and preterite
{{ copt(t="ⲛⲉ") }} / {{ copt(t="ⲉⲛⲉ") }} join the following word, which
distinguishes them from the interrogative {{ copt(t="ⲉⲛⲉ") }}. The relative
pronoun joins in every form except {{ copt(t="ⲉⲧⲉ") }}, which stands apart
and is thereby kept distinct from {{ copt(t="ⲉⲧ") }} plus second person
feminine {{ copt(t="ⲧⲉ") }}.{{ cite(t="§§ 23–28, pp. 161–162.") }}

| Joined | Separated |
|---|---|
| {{ copt(t="ⲉⲛⲉⲛⲧⲕ ⲟⲩⲱϩⲥ") }} if you were a shepherd | {{ copt(t="ⲉⲛⲉ ⲛⲧⲕ ⲟⲩⲱϩⲥ") }} are you a shepherd? |
| {{ copt(t="ⲛⲑⲉ ⲉⲧⲟⲩⲁϣⲥ") }} as you (m.) wish | {{ copt(t="ⲛⲑⲉ ⲉⲧⲉⲟⲩⲁϣⲥ") }} as you (f.) wish |
| {{ copt(t="ⲡⲏⲓ ⲉⲛⲧⲁⲡⲁⲥⲟⲛ ⲃⲱⲕ ⲉϩⲟⲩⲛ ⲉⲣⲟϥ") }} the house he entered | {{ copt(t="ⲧⲡⲏⲅⲏ ⲉⲧⲉ ⲡⲥⲱⲙⲁ ⲡⲉ") }} the spring that is the body |

### The nominal sentence

{{ copt(t="ⲡⲉ") }}, {{ copt(t="ⲧⲉ") }} and {{ copt(t="ⲛⲉ") }} stand apart, as
does a reduced pronominal subject. Till lists about twenty pairs that joining
would confuse, and notes that {{ copt(t="ⲡⲉ") }} often has no syntactic
connection to the word before it.{{ cite(t="§§ 29–33, pp. 162–164.") }}

| Joined | Separated |
|---|---|
| {{ copt(t="ⲟⲩⲁⲡⲉ") }} a head | {{ copt(t="ⲟⲩⲁ ⲡⲉ") }} he is one |
| {{ copt(t="ⲧⲉⲥⲙⲛⲧⲉ") }} its centre | {{ copt(t="ⲧⲉⲥⲙⲏ ⲧⲉ") }} it is the voice |
| {{ copt(t="ⲛⲟⲩⲛⲉ") }} root | {{ copt(t="ⲛⲟⲩ ⲛⲉ") }} they are yours (f.) |
| {{ copt(t="ⲛⲧⲕⲟⲩⲉⲣⲏⲧⲉ") }} of your foot | {{ copt(t="ⲛⲧⲕ ⲟⲩⲉⲃⲟⲗ ⲧⲱⲛ") }} where are you from? |

### Clitics

Enclitics and proclitics are written separately; joined, they read as part of
the neighbouring word. {{ copt(t="ⲛϭⲓ") }} before a plural noun is the
clearest case.{{ cite(t="§§ 34–37, pp. 164–165.") }}

| Joined | Separated |
|---|---|
| {{ copt(t="ⲛϭⲓⲛϣⲁϫⲉ") }} the discourses | {{ copt(t="ⲛϭⲓ ⲛϣⲁϫⲉ") }} that is, the words |
| {{ copt(t="ⲕⲉⲣⲱⲙⲉ") }} another man | {{ copt(t="ⲡⲕⲉ ⲉⲧⲛⲧⲁϥ") }} also that which he has |
| {{ copt(t="ϫⲉϥⲛⲁⲩ") }} that he may see | {{ copt(t="ⲧⲉⲛⲟⲩ ϭⲉ") }} now then |

### Compounds, affixes, suffixes

Join a first element that never occurs on its own, since joining it can cause
no confusion; separate anything that also occurs as a word. Suffix pronouns
join. The full form {{ copt(t="ⲧⲏⲩⲧⲛ") }} does not: its {{ copt(t="ⲱ") }} and
{{ copt(t="ⲏ") }} show it carries an accent of its
own.{{ cite(t="§§ 38–40, pp. 165–166.") }}

| Joined | Separated |
|---|---|
| {{ copt(t="ⲥⲁⲩⲏⲣⲡ") }} wine-drinker | {{ copt(t="ⲃⲱ ⲛⲉⲗⲟⲟⲗⲉ") }} vine |
| {{ copt(t="ⲣⲉϥϫⲓⲟⲩⲉ") }} thief | {{ copt(t="ⲙⲁ ⲛϣⲱⲡⲉ") }} dwelling |
| {{ copt(t="ⲁⲧⲙⲁⲁⲩ") }} motherless | {{ copt(t="ⲥⲁ ⲛⲛⲉϩ") }} oil-seller |
| {{ copt(t="ⲣⲁⲧⲛ") }} our foot | {{ copt(t="ⲣⲁⲧ ⲧⲏⲩⲧⲛ") }} your foot |

## Limits

Joining the one-letter {{ copt(t="ⲉ") }} loses the distinction between the
preposition and the circumstantial: {{ copt(t="ⲉⲩⲙⲧⲟⲛ") }} has three readings
and no spacing separates them. {{ copt(t="ⲛ") }} carries the plural article,
the negation, the genitive, the dative and the accusative, all joined. Till's
position is that a few undecidable cases are not a reason to give up a
procedure that works everywhere else.
